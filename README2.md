# madiTASKS — файл жүктеу және баға қою қосымшасы

Файл немесе папка жүктеп, күйін («Жаңа / Орындалуда / Орындалды») белгілеп, 1–5 жұлдыз баға қоятын неон 3D сайт.
Деректер `localStorage` жадында сақталады.

## Файлдар
- `index.html` — бет құрылымы
- `style.css` — неон және 3D дизайн
- `script.js` — жүктеу, папка, күй, баға

## Іске қосу
`index.html` файлын браузерде ашыңыз.
